# SLE-CPD analysis code

This directory contains the analysis scripts used for the SLE-CPD study and the comparison with conventional biomarkers. The scripts implement the four model pipelines, nested cross-validation, calibration, decision-curve analysis, missingness and imputation sensitivity analyses, SHAP summaries, and exploratory age/sex-matched analyses.

## Files

- `analysis/model1_model2_pipeline.py`: Model 1 (SLE vs healthy controls) and Model 2 (SLE vs non-SLE rheumatic disease). Set `MODEL_ID` to `1` or `2` in the script.
- `analysis/model3_model4_pipeline.py`: Model 3 (new-onset SLE vs non-SLE rheumatic disease) and Model 4 (new-onset SLE vs healthy controls). Set `MODEL_ID` to `3` or `4`.
- `analysis/traditional_marker_comparison.py`: comparison of conventional biomarkers, CPD features, and combined models.
- `requirements.txt`: Python dependencies.

## Data and privacy

Patient-level input data, prediction tables, fitted model binaries, and generated figures are excluded from this source package. Use only approved, de-identified data. Do not commit names, hospital numbers, dates of birth, contact details, or other direct identifiers.

The scripts default to relative paths under `data/`. You can instead provide paths through these environment variables:

- `SLE_CPD_MODEL1_DATA`, `SLE_CPD_MODEL1_EXTERNAL`
- `SLE_CPD_MODEL2_DATA`, `SLE_CPD_MODEL2_EXTERNAL`
- `SLE_CPD_MODEL3_DATA`, `SLE_CPD_MODEL4_DATA`
- `SLE_CPD_TRADITIONAL_DATA`

Example:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
export SLE_CPD_MODEL1_DATA=/secure/path/data1.xlsx
export SLE_CPD_MODEL1_EXTERNAL=/secure/path/external_HC_SLE.xlsx
python analysis/model1_model2_pipeline.py
```

Before publication, verify the column names, units, outcome coding, and sheet names against the approved analysis dataset. The risk strata and cut-points generated by these scripts are data-driven and should not be interpreted as clinically validated thresholds.
